# sveltekit on deno (SSR)

Пример sveltekit на deno для Timeweb Cloud Apps.

## Параметры деплоя

| Параметр | Значение |
| --- | --- |
| Runtime | `deno` |
| Фреймворк в API | `sveltekit` |
| Тип приложения | `backend` |
| Команда сборки | `deno task build` |
| Команда запуска | `deno task start` |

## Локальный запуск

```bash
deno install --allow-scripts
deno task build
deno task start
```
